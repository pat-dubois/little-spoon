# Little Spoon

Pediatric nutrition tools for dietitians. A zhuzh labs joint.

Three tools, one app, built for the bedside: fast, checkable calculations that
clinicians otherwise do by hand. No patient data is stored or sent anywhere.

Rebuild of the original peds calculator (`legacy/`). Work in progress; see `NEXT.md`.

## Design skills

The repo ships with the [taste-skill](https://github.com/Leonxlnx/taste-skill) set
installed under `.claude/skills/` and `.agents/skills/`. They are loaded automatically
by Claude Code and Codex when working on the front end.
