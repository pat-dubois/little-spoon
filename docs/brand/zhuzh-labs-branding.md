# Zhuzh Labs — Naming & Branding Guide

## The Label

**Zhuzh Labs** — Pat Dubois' personal software label for tools built for personal use, friends, family, and work.

## App Naming Convention

Every app follows the format:

> **Little [Noun]**

- "Little" is the consistent brand thread across all apps
- The noun is specific to what the tool does
- Tagline beneath: *a zhuzh labs app*

### Current & Example App Names

| Name | Purpose |
|---|---|
| **Little Spoon** | Pediatric nutrition calculator |
| **Little Dial** | Audio/radio tool (future) |
| **Little Ledger** | Budget/finance tool (future) |
| **Little Clock** | Scheduling tool (future) |
| **Little Booth** | Radio production tool (future) |

## Visual Identity

### Color System

- **Base theme:** Flexoki (dark variant)
- **"Little"** — Always rendered in rainbow gradient CSS (animated 8–10 second cycle)
- **"[Noun]"** — Clean white on the dark background
- **"a zhuzh labs app"** — Subtle, secondary text

### Why This Works

- **Rainbow "Little"** = the Zhuzh Labs signature; instantly signals the app family
- **White noun** = the individual app's identity; clean, professional, readable
- **Dark Flexoki base** = grounds everything, keeps it polished

### Visual Hierarchy

```
🌈 Little  Spoon
a zhuzh labs app
```

Rainbow identifies the family. White identifies the tool. Every new app instantly looks like it belongs.
