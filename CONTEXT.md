# Little Spoon terms

| Term | Meaning here |
| --- | --- |
| Little Spoon | The current pediatric Nutrition, Z-score and DRI / RDA app. The original blue Ped's calculator and older Little Spoon snapshots are distinct historical implementations. |
| Pulse | This project's visual status board, generated from session receipts and a GitHub ticket snapshot. |
| Session receipt | An append-only record of verified work, checks and explicitly unresolved questions. |
| Settled | Pat accepted this phase after Crystal reported the app works well. No new feature work is queued. Existing source qualifications still apply. |
| WHO age | Exact elapsed days divided by 30.4375 for growth references. Nutrition and DRI use attained calendar age. |
| Daily reference and UL | AI/RDA describes reference intake; UL is an upper limit, with nutrient-specific form/source scope. A missing UL does not mean unlimited intake is safe. |
| Vitamin units | Vitamin D shows published IU and µg pairs. Vitamin A shows µg RAE and retinol-qualified IU; its UL covers preformed vitamin A. |

Patient measurements are transient calculator inputs. Project receipts and tickets contain engineering evidence, not patient records. Exact source conventions and qualifications live in the clinical validation reports.
